# golem.fm — the golem showcase site

The static site served at **https://golem.fm** while golem.fm itself is being built:

- `/` — the golem's own interface running in your browser on a demo golem (read-only, nothing is saved);
- `/docs/` — the musicians' documentation of golem.

This repository holds **built files only**. golem itself — the code, the installer, the issues — lives at
**https://github.com/Goldoralf/golem**. Report bugs and talk there (Issues, Discussions).
