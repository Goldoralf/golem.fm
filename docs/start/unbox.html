Unbox and plug in the golem

golem

golem is software: you install it on a computer, and that computer becomes the rack. It can be a laptop with a USB sound card, or a dedicated machine in a rack case.

What you need

  • a computer — Linux (Ubuntu 24.04, the reference), Windows 10 or 11, or a Mac with Apple Silicon;
  • a USB sound card — any USB audio interface works; the reference is a Universal Audio Volt 276;
  • a pedalboard — the reference is a Behringer FCB1010 with the UnO2 chip, plugged into the sound card's MIDI; other pedalboards are described as data;
  • optionally, a touch screen (7 to 10″, laid out for 1024×600), a USB keyboard or pad controller, an electronic drum kit — and the musicians' phones.

Power, network, sound card

  • The sound card goes on its own USB port — not on a hub shared with the touch screen. golem detects it at the first start and offers to use it.
  • The network: a cable always reaches the golem. On Wi-Fi, it joins your network; with no known network, it raises its own (see The golem does not show up).
  • The pedalboard goes into the sound card's MIDI input.

First boot

Install with one line — Linux: curl -fsSL https://get.golem.fm | sh; Windows: irm https://get.golem.fm/win | iex. The installer checks the machine, installs the audio engine, asks where to install and how much sound to download, then offers to connect golem.fm and TONE3000 (you can skip both).

Then golem starts, and opens the first-install check: play, listen, press a switch — two minutes, once (see The first-install check).

One install, two ways to use it: in a window on the computer's own screen, or as a server with a tablet or a phone as the screen. Switch from Settings ▸ System ▸ Dashboard (Continue on a tablet). Start golem with this computer makes it start by itself — the dedicated-rack setup.
