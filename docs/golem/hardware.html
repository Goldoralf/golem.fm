The machine

golem

golem runs on a computer you choose. This page describes the reference machine golem is built and tested on, the sound cards it works with, and how it updates.

The reference machine

The reference rack is a 2U rack case holding a small PC (a Mini-ITX board, a Ryzen 5 8500G, 16 GB of memory, an NVMe drive), with:

  • the USB sound card — a Volt 276 — on its own USB port: inputs 1 and 2 for the instruments, the main outputs and the headphones for the sound, its MIDI ports for the pedalboard;
  • USB ports for a keyboard, a pad controller or an electronic drum kit — up to four, numbered USB 1 to 4 on the Soundcard page;
  • an Ethernet port — the always-open door to the golem;
  • an optional touch screen (7 to 10″), and an optional second Wi-Fi dongle.

A laptop with a USB sound card works the same way.

Supported sound cards

There is no list of supported cards: any USB audio interface works. golem reads what the card has — its inputs, its outputs — and shows them on Settings ▸ Gear ▸ Soundcard, where you name them (see Sound card and inputs).

  • Linux — USB audio interfaces; the computer's built-in sound chip is not offered.
  • Windows — the card's own ASIO driver. Generic drivers (ASIO4ALL and the like) are not used: they lose inputs.
  • Mac — Core Audio; not yet tested on a real Mac.

The Volt 276 is the card golem is tested with every day.

Updates

Settings ▸ About ▸ golem shows the version you run and the latest release. ⟳ Check for releases, then ⬆ Update to v… — with the list of changes. golem updates only to published releases.

On a computer used as a window, golem restarts entirely: the sound stops for about thirty seconds — never update before a gig. The audio engine (REAPER) is updated from Settings ▸ About ▸ REAPER, to the version validated for your golem release.
