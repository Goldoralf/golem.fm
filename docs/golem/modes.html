Modes: Pedalboard, Home, Jam, Rehearsal, Gig

golem

A mode tells the golem where you are: alone at home, jamming, in the rehearsal studio, on stage. The same rig does not need the same things in each place. A mode switches tools on and off, picks what the Live screen shows, and decides whether the click and the recorder start — without touching a single preset.

Pedalboard, Home, Jam, Rehearsal, Gig

Settings ▸ Mode lists the modes on the left. The red dot marks the mode the rig runs now.

| Mode | For | What it does | |---|---|---| | Pedalboard | one instrument, nothing else | every tool off: no backing, no click, no recorder, no arrangement. The mode where nothing can go wrong. | | Home | the full rig at home | everything on. The default. | | Jam | playing along | backing tracks, standards and the drum machine lead; the looper is off. The Live screen opens on the Concert page. | | Rehearsal | the rehearsal studio | everything on, the Live screen opens on the Rehearsal page, and the recorder starts by itself as soon as the Live screen is open. | | Gig | the stage | the screen is locked to Live, the take covers the whole set, the CPU runs at full speed. |

A tap on a mode opens its sheet; it does not switch to it. The sheet says if the mode is the one running (⏻ Active); otherwise its button switches the rig to it.

Switching mode takes a few seconds: tools stop or start, the pedalboard gets the mode's setlist. It is something you do when you arrive somewhere, not in the middle of a song.

What each mode changes

The sheet reads in three parts.

  • Who and where. Card: Any, or the one sound card this mode waits for. Inputs: the instruments patched on the card, one pill each (here only Guitar 1) — a pill switched off leaves that instrument's lane out in this mode, without touching the presets.

  • On stage. Tools: Backing, Standards, Sample, Drum machine, Looper, Riff — each one on or off. Live screen: which page Live opens on (Pedalboard, Rehearsal or Concert). Foot list: the setlist the pedalboard gets when you enter the mode.

  • Time and takes. Click: Off (never), Per preset (each preset's Click block decides) or Manual (a switch of its own). REC: whether this mode records. Arrangement: whether songs run their parts by themselves.

A pill is one switch; a joined bar is one choice among several.

A mode never removes anything. A tool switched off is still in your presets: its tile says Off in Gig, it gets no footswitch, and it comes back in the next mode that allows it. You can still edit it in the Designer — you build at home, you play on stage.

Comparing modes

▦ All modes side by side shows the whole table at once. Read a row to see what changes from one place to another: the Live screen goes from Pedalboard at home to Rehearsal in the studio and Concert on stage; the recorder is off only in Pedalboard. Tap a column to open that mode's sheet.

Locking the screen and the 2 s exit

Gig locks the screen: the other hubs disappear, only Live remains. The Live page still works — if the pedalboard fails, the screen is your backup — but nothing on it can rebuild your rig or open a menu by accident.

To leave, hold the mode badge for 2 seconds (or the golem logo, in a locked mode). The badge shows the hold; let go before 2 s and nothing happens. The golem goes back to Home. If a take is recording and Home records somewhere else, the golem asks before it switches.

The badge is there in every mode except Home: holding it is always the way back.
